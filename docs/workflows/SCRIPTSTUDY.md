## Best workflow for using script in your study

Do not try to add huge chunks of screenplay. Use a small script snapshot.

For this study, I would include:

* the scene heading
* 3–8 lines of the scene description
* maybe one line that captures the contrast with the hallway

Then annotate it:

* underline words that imply **space**
* circle words that imply **props**
* box words that imply **character psychology**
* mark where the final film adds more than the script directly states

Take the script excerpt and write:

* what the script explicitly says
* what the finished set adds
* what the finished set implies that is not literally in the script

Make a rough top-down guess of:

* window wall
* chair
* counter/sink area
* standing zone
* camera direction
Do not worry about accuracy. This trains spatial thinking.

Write 3 categories:

* hero details
* supporting details
* atmosphere/background details

For K’s room, for example, the chair and Pale Fire matter more than random clutter because the room is defined by restraint, not abundance. The script itself points to that sparseness and that book.
